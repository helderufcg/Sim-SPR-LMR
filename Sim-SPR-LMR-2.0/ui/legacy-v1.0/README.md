# Legacy interface files — version 1.0

This directory contains historical copies of the Qt Designer (`.ui`) files found in the official version 1.0.

These files are provided only as visual and functional references for the development of version 2.0. They are not authoritative sources for the current interface and must not be used to automatically regenerate or overwrite the version 2.0 Python modules.

## Organization

- `root/`: `.ui` files originally located at the root of `Sim-SPR-LMR-1.0`.
- `Sim-LMR-Interface--main/`: `.ui` files originally located in the corresponding version 1.0 directory.

The relative directory structure was preserved because version 1.0 contains files with duplicate names that may represent different revisions of the same screen.
